Widget test pages

Static pages that embed a widget from query parameters, with a small debug panel.

Pages

Path<html lang>Content language
/en/enEnglish
/de/deGerman
/pt-PT/pt-PTPortuguese (Portugal)
/pt/ptPortuguese
/nolang/(no attribute)English
/widget/en, or ?hl=<code> / hl=noneEnglish, generic page for any widget

Each language folder has index.html and page2.html. Links between them keep every query parameter except lang.

Query parameters

idWidget id(s). Several allowed: id=a,b.
placeinline (header slot, default), body (end of body; alias floating), both.
lazy=1|0Force lazy loading on or off. Default: inline is lazy, body is not.
ga / gtmLoad real gtag.js / GTM. Without them, analytics calls are only logged in the panel.
analyticsgtag (default stub), datalayer (dataLayer only), none.
nostorage=1localStorage throws SecurityError (blocked-storage simulation).
watchComma-separated URL substrings; matching network requests are counted in the panel.
panel0 hides the debug panel, min starts it collapsed.
hl/widget/ only: html lang to set (none removes it).
